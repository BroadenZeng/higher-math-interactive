# 高等数学交互课件

**让数学概念在观察与探索中逐步清晰。**

这是一套面向高等数学课堂持续制作的交互课件。从问题出发，结合动态图像、逐步推导与课堂练习，为理解概念和组织教学提供支持。

## 课件特色

- **观察与思考**：通过可操作的函数图像，观察函数与曲线的变化。
- **逐步呈现**：按课堂讲授节奏展示问题、推导与结论。
- **课堂书写**：支持画笔批注、白板、撤销和保存笔迹。
- **例题与练习**：提供可展开的解答，方便课堂讲解与课后回顾。

## 使用方式

下载项目后，打开对应章节的 HTML 文件，即可在浏览器中使用。建议使用 Microsoft Edge；浏览器的文件访问权限可能影响笔迹的保存位置。

## 源码维护

课件共用的样式和放映工具位于 `公共资源`，各章节的图像脚本保存在对应章节目录中。修改公共资源后，应检查各章节和新课件模板。

源码格式由 `.editorconfig` 和 Prettier 配置统一。安装 Node.js 后，可在项目目录运行以下命令检查格式（MathJax 第三方文件除外）：

```sh
npx prettier@3.6.2 --check "**/*.{html,js,css}"
```

将 `--check` 改为 `--write` 可整理格式。格式检查不能替代课堂放映和交互测试。
